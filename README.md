# 流程计时器 v0.3 原型

甘特图式时间线：名称标签 + 时长条真实比例 + 拖拽排序 + 自动连续提醒。打开即用、无广告、离线可用。

## 怎么用

**电脑**：双击 `index.html`，浏览器打开即可。
**手机**：把整个文件夹放到手机，或局域网共享后在手机浏览器打开。
**投屏上课**：点右上角「⛶ 全屏」，大圆环 + 大字投屏很醒目，空格键控制。

## 功能（v0.3）

- **甘特图式时间线**：每行 = 拖拽手柄 ⠿ + 名称标签 + 时长条。默认上课五环节（情境导入 5 / 核心输入 100 / 强制休息 15 / 实战输出 90 / 总结答疑 30）
- **真实比例时长条**：条宽按真实秒数伸缩——100 分钟是 5 分钟的 20 倍宽，一眼看出时间分配；条内显示时长（窄条自动省略）
- **拖拽排序**：按住 ⠿ 手柄（或整行）上下拖动调整顺序，实时保存
- **自动连续提醒**：点「开始流程」→ 事件 A 到点响铃（三连音 ×3 轮）→ 等铃声播完自动开始事件 B → …直到流程结束，全程无人值守
- **进度玻璃管**：当前事件时长条内，金沙暖色填充从左往右推进，时间用完正好填满
- **拖入圆环即启动**：把某行拖进左边大圆环，立即启动该事件倒计时
- **点击跳转**：播放中点击某行直接切到该事件；「跳过」按钮/→ 键跳下一个，← 键回上一个
- **添加/删除事件**：虚线表单添加（名称+时长），悬停行右上角 × 删除，「恢复默认」一键还原
- **当前事件高亮**：名称标签变蓝，圆环显示剩余时间 + 当前事件名（如「核心输入 · 2/5」）
- **可视化大圆环**：剩余时间环形消退，最后 1 分钟变橙，到点变红闪烁
- **全屏**：只剩圆环+时间+当前事件名，空格开始/暂停，Esc 退出

## 键盘

- 空格：开始 / 暂停 / 继续
- →：下一个事件　←：上一个事件

## 怎么验（手动测试清单）

1. 看时间线：核心输入(100min) 的时长条应显著长于 情境导入(5min)，约 20 倍
2. 点「开始流程」→ 情境导入 5 分钟倒数，名称标签变蓝，时长条内金沙从左往右填
3. 暂停 → 继续 → 时间衔接无跳变
4. 「跳过」→ 切到核心输入（2/5）
5. 按住 ⠿ 手柄把「强制休息」拖到「情境导入」后面 → 顺序变了（刷新页面还在）
6. 虚线表单添加「板书演示 10」→ 出现新行，时长条长度介于 5min 和 15min 之间
7. 悬停行右上角 × 删除 → 删除成功
8. 设个 10 秒事件放最前 → 到点响铃三遍后自动进下一个 → 流程播完显示「流程完成！」
9. 播放中把某行拖进左边圆环 → 立即启动该事件
10. 全屏 → 只剩圆环+时间+当前事件名，空格可控，Esc 退出
11. 手机打开：可添加/删除，拖拽在手机上暂不支持（桌面端用）

## 已知边界（第一版不做）

- 手机上拖拽排序暂不支持（HTML5 DnD 桌面为主），可用「删除+重加」调整
- 事件时长修改：删掉重加（v0.4 计划加编辑）
- 铃声是合成音，不是真实音频文件
- 无小组件/灵动岛（那是原生 APP 的事）

## 文件

- `index.html` — 页面（开发用）
- `style.css` — 样式
- `app.js` — 逻辑（事件存 localStorage）
- `build-single.js` — 构建脚本：生成单文件版
- `流程计时器-单文件版.html` — **发给朋友测试用，一个文件搞定**（微信直发，双击即用）

## 发给朋友测试

发 `流程计时器-单文件版.html` 一个文件就行。朋友收到后电脑双击、手机浏览器打开。

**改版后**重新生成单文件版：`node build-single.js`（原型文件夹内运行）。
